{%- comment -%} The install line is spelled out here too: opening a row needs JavaScript, and "how do I run this" should not depend on that. {%- endcomment -%}

The npm tools install with npm i -g <package> or run straight from npx; the PyPI ones install with pipx install <package> or run from uvx. Open a row for that package's own install line and examples. The downloads column is the last 12 months, drawn as the last {{ totals.spark_weeks }} weeks beside it. Figures come from the public npm downloads API and from pypistats.org — PyPI publishes no counts of its own — up to the last complete day, with PyPI mirror traffic excluded. Recently published packages may show no counts until a full period is aggregated.
