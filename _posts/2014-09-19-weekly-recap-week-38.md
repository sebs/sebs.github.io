This week was more about building my own things aka website.

[Jekyll](http://jekyllrb.com/) is still one hell (good) of a blogging and web site system. If you are hosting your own Wordpress blog and you are technical capable: Look into Jekyll. It’s a complete static website generator using markdown as a file format. I love it and I am still a bit on the learning curve.

There is a [yeoman generator for Jekyll](https://github.com/Thomas-Lebeau/generator-jekyll)and Bootstrap that makes some things easy. You might be better off with starting a plain Jekyll project and wiring everything up yourself. However it is a good if you want to see how things can be wried up and have a basic idea how bootstrap works.

I found out what copywriting is. It’s essentially writing for marketing reasons. Aha. [Thank you wikipedia](http://www.wikiwand.com/en/Copywriting). One of these words that I listened to multiple times but never really questioned what they imply.
